# 규정 원본

챗봇이 답변 근거로 삼는 원천 문서다. 여기를 고치면 재색인이 필요하다.

## 파일

| 파일 | 카테고리 |
|---|---|
| `01-출결.md` | 출결 |
| `02-훈련장려금.md` | 훈련장려금 |
| `03-수료.md` | 수료 |
| `04-시설-장비.md` | 시설·장비 |
| `05-회의실.md` | 회의실 |

## 조항 번호 체계

챗봇이 출처를 인용하려면 가리킬 주소가 있어야 한다. 조항 번호가 그 주소다.

```
제3장 출결
  제12조(지각의 기준)
```

인용은 `01-출결.md 제12조` 형태로 나간다. **조항 번호는 재사용하지 않는다.**
조항을 삭제하면 번호를 비워두고, 새 조항은 뒤에 붙인다. 번호를 돌려쓰면 과거 답변의
출처가 엉뚱한 곳을 가리킨다.

## frontmatter

모든 파일이 아래 세 값을 갖는다. 색인 시 청크마다 메타데이터로 붙는다.

```yaml
---
category: 출결
version: 1.0.0
effective_date: 2026-03-01
---
```

규정을 고치면 `version`을 올리고 `effective_date`를 갱신한다. 재색인 잡이 이 값을
보고 갱신 대상을 판정한다.

## 표

조건부·계산형 질문(B유형)은 표가 있어야 답이 나온다. "3일 결석하면 얼마 깎여요"에
답하려면 결석일수별 감액표가 문서에 있어야 한다.

**표는 청킹할 때 쪼개지 않는다.** 행이 잘리면 답이 틀린다.

## 지금 수치는 임의값이다

이 문서는 챗봇 개발과 평가를 위한 초안이다. 아래 값은 그럴듯하게 채운 것이지
확정된 것이 아니다. 팀에서 실제 값으로 바꿔야 한다.

- 지각 기준 10분
- 결석일수별 감액률
- 수료 출석률 80%
- 노트북 대여 30일
- 회의실 예약 2주 전

## 일부러 빼둔 것

골든셋의 함정 질문용이다. 규정에 없는 것을 물었을 때 챗봇이 "모른다"고 답하는지
재려면 없는 영역이 필요하다. 아래는 의도적으로 다루지 않았다.

- 병가·공가
- 재수강
- 주차
- 식대·간식

**나중에 이 항목을 규정에 추가하면 골든셋의 함정 질문도 같이 고쳐야 한다.**
