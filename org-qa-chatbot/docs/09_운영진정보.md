# 운영진 정보

포텐업 구성원들의 커리어 여정을 서포트하는 운영진 소개입니다.

## 총괄 김희창

"포기하고자 하면 핑계를 찾고, 다짐을 하면 방법을 찾는다."
앞으로의 도전을 응원합니다!

## 커리어 코치 고은해

- 포텐업의 최종 목표인 취업을 위해 '주도적으로 커리어 스토리를 설계'하는 여정을 함께합니다.
- 구성원의 강점과 취업 목표를 찾고 구직 스킬을 쌓아갈 수 있도록 지원합니다.
- 좋은 에너지를 많이 나누고 싶어 하니 언제든 편하게 찾아가면 됩니다.

## 운영진 김아름

- 포텐업 생활 운영 전반을 담당하며, 구성원들이 학습에만 집중할 수 있도록 모든 환경을
  책임지고 관리합니다.
- MBTI는 ESFJ로, 누군가를 챙기고 도와주는 것을 좋아하는 성격입니다.
- 먼저 인사 건네는 것을 좋아합니다.

## 운영진 최자경

- 포텐업 생활 전반을 관리합니다.
- MBTI는 ISTJ로, 눈앞에 마주한 상황을 빠르고 정확하게 해결하고자 노력합니다.
  문의 및 불편 사항이 생기면 언제든 편한 방법으로 연락하면 됩니다.
- 6개월간 후회 없는 시간이 될 수 있도록 최선을 다해 지원합니다.

## 운영진 이정기

- 포텐업 생활이 불편하지 않도록, 그리고 후회 없도록 늘 가장 가까운 곳에서 지원합니다.
- 구성원이 직접 움직이고 성장할 수 있도록 집요하게 돕습니다.
- MBTI는 ESFJ이고, 다른 사람들을 돕는 것에 보람을 느낍니다.
