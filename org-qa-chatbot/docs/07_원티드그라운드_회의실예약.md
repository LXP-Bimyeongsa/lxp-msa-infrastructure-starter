# 원티드그라운드 회의실 예약

## 01. 예약 대상 공간

그라운드 내에 예약제로 운영되는 공간은 다음과 같습니다.

- 3F 멘토링 룸
- 4F 멘토링 룸
- B1F (스튜디오)
- B1F (대규모 스터디, 스크린 및 음향 사용)

## 02. 예약 방식

멘토링룸을 포함한 공간 예약은 회의실 예약 페이지를 통해 진행됩니다.

- 접근 경로: 그룹웨어 링크 접속 > 회의실 예약
- 예약자 이름 기재 형식: `1-4(김포텐)` / `2-5(김포텐)` / `3-3(김포텐)`

### 교육 과정별 예약 기재 방식

| 소속 | 기재 형식 |
| --- | --- |
| 3층 구성원 | 1-4 (김포텐) |
| 4층 구성원 | 2-5 (김포텐) |
| 6층 구성원 | 3-3 (김포텐) |

## 03. 예약 주의 사항

- 회의실은 매주 월요일 선착순 예약제로 운영됩니다.
  (강사님 / 커리어코치님 1:1 상담이 우선 진행됩니다.)
- 주말·공휴일·휴강일은 예약창이 열려 있더라도 그라운드 미출근일이므로 회의실 이용이
  불가합니다.
- B1F 행사 예약이 있는 경우(프로젝트 발표회 등) 지하 1층 스튜디오 이용이 제한됩니다.
- 회의실 1일 최대 이용 시간은 2시간입니다.
- 동일 팀이 예약자만 변경하여 반복 이용하는 행위는 제한됩니다.
- 퇴실 시간은 반드시 준수해야 하며, 이용 후에는 다음 팀을 위해 원상 복구해야 합니다.
