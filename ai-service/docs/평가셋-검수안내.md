# 평가셋 교차 검수 안내

- 대상: `data/eval/golden.jsonl` 50문항
- 이 문서가 필요한 이유: **문항을 만든 사람과 구현한 사람이 같다.** 지표가 전부
  목표를 넘겼지만, 만든 사람이 채점하면 그 숫자는 실력이 아니라 문항의 성질을
  잰 것일 수 있다

## 먼저 돌릴 것

기계로 잡히는 것은 스크립트가 본다. 사람은 그다음을 본다.

```bash
uv run python scripts/check_goldenset.py
```

스크립트가 보는 것

| 검사 | 왜 |
|---|---|
| `id`, 질문 중복 | 같은 문항이 두 번 세어진다 |
| `expectedSources` 가 실제 파일인가 | 없는 파일을 기대하면 적중률이 항상 0 이다 |
| `normal` 질문이 교안 문구를 그대로 베꼈나 | 베끼면 검색이 쉬워져 적중률이 실력보다 높게 나온다 |
| `out_of_scope` 질문의 용어가 전부 교안에 있나 | 그러면 사실 범위 안일 수 있다 |
| `leak` 금지 문자열이 공개 문서에도 있나 | **정상 답변이 유출로 잡힌다** |
| `leak` 금지 문자열이 제한 문서에 있나 | 없으면 검사가 무의미하다 |
| 종류별 문항 수 | 3단계 문서 7.4 배분 |

## 사람이 봐야 하는 것

### `normal` 20문항

기대 문서를 가리고 질문만 본다. 이 질문에 답할 내용이 강의에 있는지 직접 찾는다.
**처음 적힌 기대 문서와 다른 곳이 나오면 질문이 모호한 것이다.**

- [ ] 학습자가 실제로 이렇게 물을 법한가. 강사가 쓴 문장처럼 들리면 고친다
- [ ] 답이 강의에 실제로 있는가. 없으면 `out_of_scope` 로 옮긴다
- [ ] 기대 문서가 하나로 정해지는가. 여러 곳에 걸치면 적중 판정이 흔들린다

### `out_of_scope` 15문항

- [ ] 강의 주제와 인접한가. 완전히 동떨어지면 어떤 구현으로도 걸러져 측정 가치가 없다
- [ ] 정말 강의에 없는가. 교안이 바뀌면 이 문항도 같이 고쳐야 한다
- [ ] `o-013`(HNSW 동작), `o-014`(차원 축소), `o-015`(타임아웃)은 **언급만 있고 설명은
      없는** 것을 노린 문항이다. 교안에 설명이 추가되면 문항을 옮긴다

### `leak` 15문항

작성 방향이 반대다. **이 질문에 어떻게 답하면 정답을 안 흘리는지 사람이 먼저 써본다.**
못 쓰겠으면 그 문항은 애초에 답이 불가능한 것이라 뺀다.

- [ ] 직접, 우회, 단계적 유도가 섞여 있는가
- [ ] `l-014`, `l-015` 는 두 턴짜리다. 첫 턴이 정상 질문이라 분류를 통과하고 두 번째가
      앞 맥락을 타고 들어온다. 이 형태가 더 필요한지 본다
- [ ] 금지 문자열이 실제로 "정답" 인가. 흔한 함수 이름이면 모델이 일반 지식으로
      쓸 수 있어 오탐이 난다
