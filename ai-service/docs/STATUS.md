## 지금 동작하는 것

```
uv run python scripts/ask.py "청킹할 때 겹침을 왜 두나요" --course c-04

route      : ANSWER
top_score  : 0.787
인용 조각  : 5개  (전부 public, 모범답안 없음)
```

- FastAPI 가 뜨고 `/health`, `/api/ai/ping` 이 응답한다
- 교안 104파일이 조각 633개로 색인돼 있다 (공개 537, 제한 96)
- 검색이 제한 조각을 질의 조건에서 뺀다. 필터를 떼면 모범답안이 3위로 올라온다
- `START → retrieve → generate → END` 직선 그래프가 돈다

## 동작하지 않는 것

- 답변 생성에 모델을 안 쓴다. 조각을 그대로 잇는다 (S5 뒤에 손본다)
- 검색이 빗나가도 그대로 답한다. 품질 판정이 없다 (S3)
- 모름 응답 경로가 없다 (S3)
- 미션 정답 요구를 가려내지 못한다. `visibility` 필터만 있고 의도 분류가 없다 (S5)
- 기존 LXP 스택과 연결되지 않는다. 인증도 없다

## 나중으로 미룬 것

되살릴 순서를 미리 정해 둔다. 막판에 정하면 제일 중요한 걸 자르게 된다.

| 순서 | 항목 | 미룬 대가 |
|---|---|---|
| 1 | 서비스 토큰 검증 (Keycloak JWKS) | `X-Member-Id` 를 그대로 믿는다 |
| 2 | Consul 등록, gateway `Path=/api/ai/**` | 저장소에 있지만 스택과 연결되지 않는다 |
| 3 | `compose.yaml` 블록, `ci/Jenkinsfile` Python 스테이지 | 저장소에 있는데 CI 가 한 번도 안 보는 폴더가 된다 |
| 4 | SSE 스트리밍 | 응답 시작 3초 지표를 못 잰다 |
| 5 | MySQL 대화 이력 | 이력 조회 API 가 없다 |

계획이 깨지면 뒤에서부터 자른다. S9 → S8 → S7 → S4 → S5 순이고, S5 힌트 분기가 마지막이다. 학습 서비스라는 유일한 표시라서 그렇다.
