# 튜터 테스트 콘솔 계획

- 날짜: 2026-08-20
- 대상: `frontend/tutor-console/` (신규)
- 상태: 2장의 결정 둘이 정해졌다 (2026-08-20). U1~U4 를 만들었고 U5 는 보류다 (AI-08, AI-09)
- 이 문서의 목적: 왜 화면이 필요한지, 어디까지 만들고 무엇을 안 만드는지 먼저 못박는다

## 한 줄

`POST /api/ai/chat` 을 브라우저에서 두드리고 route, intent, top_score, 인용을 눈으로 보는 한 장짜리 화면.

## 1. 왜 지금 화면인가

튜터를 확인하는 수단이 지금 셋인데 셋 다 다른 곳에서 막힌다.

| 수단 | 보이는 것 | 막히는 곳 |
|---|---|---|
| `scripts/ask.py` | 상태 전부 (`search_query`, `retry`, `blocked` 까지) | API 를 안 거친다. 계약이 깨져도 모른다 |
| `app/eval/run_eval.py` | 15문항 지표 | 고정 문항이다. 즉흥 질문을 못 넣는다 |
| `curl` | API 응답 그대로 | Git Bash 가 한글 본문을 깨뜨려 질문마다 임시 파일을 쓴다 (CLAUDE.md) |

세 번째가 특히 나쁘다. 질문 한 글자 바꾸는 데 파일을 새로 쓴다. 브라우저 `fetch` 는
본문을 UTF-8 로 고정해 보내므로 이 함정 자체가 없어진다.

그리고 남은 작업 넷이 화면 없이는 진행이 안 된다.

| 남은 작업 | 화면이 있어야 하는 이유 |
|---|---|
| A5 힌트가 미션 내용을 추측한다 | 같은 미션을 여러 표현으로 물으며 봐야 한다 |
| A4 교차 검수 | 만든 사람 아닌 사람이 눌러야 한다. 파이썬 환경 설치를 요구할 수 없다 |
| A4 평가셋 45문항 확장 | 후보 질문을 즉석에서 던져보고 골라야 한다 |
| B4 SSE 스트리밍 | 붙일 때 받는 쪽이 이미 있어야 첫 응답 3초를 잰다 |

## 2. 착수 전에 정한 것 둘

### 2.1 8086 은 이미 다른 `ai-service` 가 쓰고 있다

결정이라기보다 발견이다. 이 저장소에 `ai-service` 라는 이름이 둘이고 채팅 경로까지 같다.

| | 튜터 (`ai-service/`) | 조직 규정 QA (`org-qa-chatbot/ai-service/`) |
|---|---|---|
| 실행 | 로컬 `uv run uvicorn` | `compose.yaml`, 컨테이너 `lxp-ai-service` |
| 호스트 포트 | 8086 | **8086** |
| 채팅 경로 | `POST /api/ai/chat` | **`POST /api/ai/chat`** |
| 요청 본문 | `{question, course_id, lang, thread_id}` | `{question}` (나머지 키는 무시된다) |
| 인증 | `X-Member-Id` 없으면 401 | 헤더를 안 본다 |
| 응답 | JSON 한 벌 | SSE 스트림 |
| 게이트웨이 | 아직 없다 (B2) | `Path=/api/ai/**` → `lb://ai-service` 가 이미 있다 |

`compose.curriculum.yaml` 이 8087 로 비켜간 이유가 이것이고, 튜터 `config.py` 의
"8086 은 비어 있는 번호" 주석은 그보다 앞서 쓴 것이다.

**콘솔에 그대로 걸린다.** 스택이 떠 있는 채로 콘솔이 `localhost:8086` 에 질문을 보내면
규정 챗봇이 200 을 돌려준다. 본문이 SSE 라 `res.json()` 이 깨지고, 화면에는 튜터가
고장난 것처럼 보인다. 실제로는 다른 서비스에 물어본 것이다. 이런 실패는 원인을 못 짚는다.

**그래서 콘솔은 붙는 순간 상대를 확인한다.** `GET /health` 의 `project` 를 본다.

| 응답 | 판정 |
|---|---|
| 200, `project: "lxp-ai-tutor"` | 튜터다 |
| 404 | 규정 챗봇이다. 그쪽은 `/actuator/health` 만 있다 |
| 연결 실패 | 안 떠 있다 |

`index_ready: false` 면 보내기 버튼을 잠근다. 색인 없이 물으면 전부 모름 응답인데
화면만 보고는 그게 색인 탓인지 판정 탓인지 구분할 수 없다.

**정한 것: 8086 을 그대로 두고 콘솔이 확인만 한다. 정리는 Consul 등록(B2) 때 한다.**
포트를 옮기면 `config.py`, STATUS, 문서 셋을 같이 고쳐야 하고
서비스 이름 중복은 그대로 남는다. 이름과 포트는 B2 에서 Consul 등록을 정할 때
한 번에 정리하는 편이 싸다.

### 2.2 브라우저는 지금 8086 에 못 붙는다

`app/main.py` 는 CORS 를 일부러 안 연다. 게이트웨이 뒤에 설 것이고, 지금 열면 닫는 것을
잊기 때문이다. 그런데 `X-Member-Id` 는 커스텀 헤더라 preflight(OPTIONS)를 부르고
서버는 그걸 405 로 돌려준다. **화면이 아무 요청도 못 보낸다.** 에러는 브라우저 콘솔에만 남는다.

| 안 | 하는 일 | 대가 |
|---|---|---|
| **A. nginx 로 같은 출처를 만든다** | 정적 파일을 8093 에 띄우고 `/api/ai/` 를 `host.docker.internal:8086` 으로 프록시 | 컨테이너 하나, 루트 compose 수정 |
| B. 개발용 CORS 스위치 | `DEV_CORS_ORIGINS` 가 비면 꺼진 채로 돈다 | 안 열기로 한 결정을 되돌린다. 기본값이 꺼짐이어도 코드에는 남는다 |
| C. FastAPI 가 정적 파일 서빙 | `app.mount("/console", ...)` 로 `../frontend/tutor-console` | 서비스가 저장소 바깥 경로를 안다. 이미지에는 그 폴더가 없어 조용히 안 붙는다 |

**A 로 정했다.** 기존 화면 둘이 이미 같은 모양이고(nginx + 정적 한 장), 같은 출처가
되면 CORS 가 생기지 않으므로 서버 결정을 건드릴 일이 없다. B2 에서 게이트웨이가 붙어도
콘솔은 안 고친다. `apiBase` 가 처음부터 빈 문자열이고, 바뀌는 것은 nginx upstream 한 줄이다.

A 의 함정 하나. 컨테이너 안에서 `localhost` 는 컨테이너 자신이다. `proxy_pass
http://localhost:8086` 은 502 가 난다. Docker Desktop 은 `host.docker.internal` 이
그대로 되고, 리눅스면 `extra_hosts: ["host.docker.internal:host-gateway"]` 를 넣는다.

## 3. 무엇을 만드는가

```
frontend/tutor-console/
  index.html     화면 한 장. 빌드 도구 없음
  nginx.conf     /api/ai/ 프록시 (2.2 A 안일 때만)
```

이름을 `tutor-console` 로 둔다. `client` 는 사용자 화면이고 `demo-console` 은 사가를
단계별로 돌리는 시연용이다. 이건 튜터가 **왜 그렇게 답했는지**를 보는 화면이라 셋 다 다르다.

프레임워크를 안 쓰는 이유는 `frontend/README.md` 의 판단 그대로다. 여기서 보여줄 것은
백엔드의 판단이지 프론트엔드가 아니다.

### 화면

```
+---------------------------------------------------------------+
| LXP 튜터 콘솔    ● lxp-ai-tutor  색인 준비됨   memberId [ 1 ]  |
+----------------+----------------------------------------------+
| 시나리오       |  ANSWER   intent CONCEPT   0.787   2.8s      |
|  · 정상 질문   |  +----------------------------------------+  |
|  · 미션 정답   |  |  답변 본문                             |  |
|  · 범위 밖     |  +----------------------------------------+  |
|  · 맥락 이어받기|  근거 5                                     |
|                |   0.787  c-04/lessons/04-chunking...#3       |
| course [c-04]  |   0.761  c-04/lessons/05-rag-pipeline.md#1   |
| thread ab12cd  |  ------------------------------------------  |
| [새 대화]      |  질문 [                          ] [보내기]  |
+----------------+----------------------------------------------+
```

route 마다 화면을 다르게 준다. `ChatResponse` 가 route 를 첫 필드로 둔 이유가 그것이다.

| route | 화면 |
|---|---|
| ANSWER | 답변 + 근거 목록 |
| HINT | 힌트 표시. 근거 자리에 "검색하지 않았다" |
| NO_EVIDENCE | 모름. 검색은 했고 근거가 부족했다 |
| OUT_OF_SCOPE | 모름. 분류에서 닫혔다. 검색을 안 했다 |

뒤 둘을 화면에서 갈라야 고칠 곳이 갈린다. 전자가 쌓이면 검색을 고치고 후자가 쌓이면
안내 문구를 고친다.

## 4. 슬라이스

| | 내용 | 완료 조건 |
|---|---|---|
| U1 | 화면 한 장, 질문 하나, route·intent·top_score·경과 ms | 한글 질문이 안 깨지고 ANSWER 와 근거 5개가 뜬다 |
| U2 | `/health` 로 상대 확인, 색인 없으면 잠금 | 규정 챗봇 쪽에 붙이면 경고가 뜬다 |
| U3 | thread 유지와 새 대화 | "청킹이 뭔가요" → "그거 왜 필요한데요" 가 ANSWER. 새 대화로 뒤엣것만 물으면 OUT_OF_SCOPE |
| U4 | 시나리오 프리셋 넷 | 설계 원칙 셋이 버튼 네 번으로 보인다 |

U3 의 완료 조건은 STATUS 의 체크포인터 대조군을 그대로 옮겼다. 대조군이 없으면 2턴이
답한 것이 이력 때문인지 운인지 구분되지 않는다.

U5 는 브라우저가 `golden.jsonl` 을 읽어야 해서 서빙 경로가 하나 더 필요하다. A4 교차
검수를 화면으로 돌릴 생각이면 값이 크지만, U1~U4 를 본 뒤에 판단한다.

## 5. API 가 주는 것과 안 주는 것

화면에 그릴 수 있는 것은 여섯이다. `thread_id`, `route`, `answer`,
`citations(course_id, seq, source_path, score)`, `intent`, `top_score`.

| 없는 것 | 왜 | 콘솔의 처리 |
|---|---|---|
| `blocked` (가드레일 사유) | 일부러 뺐다. 왜 막혔는지 알려주면 우회 방법을 알려주는 셈이다 | 화면에 안 낸다. 서버 로그를 본다 |
| `search_query`, `retry`, `graded_ok` | 계약이 아니라 턴 내부 상태다 | `ask.py` 로 본다 |
| 조각 본문 | 엔드포인트가 네 키만 남긴다 | 경로와 점수만 띄운다 |
| 강의 목록 API | 없다 | `c-01`~`c-11` 을 화면에 박는다. 교안이 실물로 갈릴 때(AI-06) 같이 고친다 |

**U1 에서 API 계약은 안 바꾼다.** 화면이 부족한 것과 계약이 부족한 것을 먼저 갈라놔야,
나중에 필드를 늘릴 때 그게 화면 편의인지 실제로 필요한 것인지 구분된다.

## 6. 예상되는 함정

| 어디 | 증상 | 원인 |
|---|---|---|
| nginx | `/api/ai/chat` 이 502 | 컨테이너 안 `localhost` 는 컨테이너 자신이다 |
| 포트 | 200 인데 JSON 파싱이 깨진다 | 규정 챗봇에 물어봤다. 본문이 SSE 다 |
| 인증 | 전부 401 | `X-Member-Id` 를 안 실었다. 없으면 401 이 정상이다 |
| 답변 | ANSWER 본문이 조각 덩어리로 길다 | 고장이 아니다. 생성에 모델을 안 쓴다 (S2 자리표) |
| 답변 | 마크다운이 원문 그대로 보인다 | 렌더러가 없다. U1 은 `white-space: pre-wrap` 로 둔다. CDN 을 붙이면 빌드 도구 없음이 깨진다 |
| 대기 | 3~4초 동안 멈춘 것처럼 보인다 | 스트리밍이 없다 (B4). 로딩 표시와 경과 ms 가 필수다 |

## 7. 하지 않는 것

- 로그인. Keycloak 토큰은 B1 뒤다. 지금은 `X-Member-Id` 입력 칸 하나로 둔다
- 대화 이력 조회. 조회 API 가 없다 (B5). 이력은 브라우저 메모리에만 둔다
- 게이트웨이 경유. 8086 에 직접 붙는다. B2 가 붙으면 nginx upstream 만 바꾼다
- 사용자용 화면. 이건 개발자가 보는 콘솔이다. `client` 에 튜터를 얹는 것은 별개 작업이다

파일로 두면 루트 compose 가 하나 더 늘고, 여기 넣으면 발표 때도 같이 뜬다.
